# Revisión Sistemática: Modelos de Delegación Humano-IA en Fraude Financiero

Este repositorio contiene el código de procesamiento de metadatos y visualización estadística asociado al artículo: Eficacia de modelos de delegación humano-IA en la detección de fraude financiero bajo restricciones de capacidad operativa.

Contenido del Repositorio

article_data.ipynb: Cuaderno en Python (Pandas, Matplotlib, Seaborn) que tabula la matriz de sistematización, ejecuta la auditoría de suficiencia metodológica sobre los estudios cuantitativos y genera las figuras de fragmentación analítica y dosis-respuesta.
